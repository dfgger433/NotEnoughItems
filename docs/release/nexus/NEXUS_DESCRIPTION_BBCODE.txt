[size=5][b][color=#35d6e8]◆ 模组简介 / OVERVIEW[/color][/b][/size]

[b]English[/b]
[b]Not Enough Items (NEI)[/b] adds a searchable item catalog, recipe and usage lookup, and bookmark-based crafting chains to the vanilla inventory and the optional Unknown Inventory Terminal in [i]Casualties: Unknown[/i]. It runs on BepInEx 5 for Mono and supports batch crafting through compatible versions of the optional Together mod.

[b]中文[/b]
[b]Not Enough Items (NEI)[/b] 为《Casualties: Unknown》的原版背包和可选的 Unknown Inventory Terminal 提供物品搜索、配方与用途查询、书签分组和多层合成链规划。

[line]

[size=5][b][color=#35d6e8]◆ 核心特性 / FEATURES[/color][/b][/size]

[b]1. 物品索引与高级检索 (Catalog & Advanced Search)[/b]
[list]
[*] [b]有序网格布局[/b]：右侧目录保持稳定索引排列，拾取、丢弃或刷取均不会打乱目录顺序。
[*] [b]高级前缀过滤[/b]：支持 [color=#ffb454]@模组名[/color]（如 [i]@CasualtiesUnknown[/i]）、[color=#ffb454]$标签[/color]、[color=#ffb454]#描述文字[/color]、[color=#ffb454]&内部ID[/color]、[color=#ffb454]-排除项[/color] 及 [color=#ffb454]|[/color] 备选词。
[*] [b]拼音检索互操作[/b]：配合可选的 [i]Just-Unknown-Characters[/i] 模组，支持全拼与拼音首字母检索（如 [i]st[/i] 查石头）。
[*] [b]Shift 快捷复制[/b]：按住 [b]Shift[/b] 悬停任意物品，点击 ID 或模组名称行即可直接复制到剪贴板。
[/list]

[b]2. 配方与用途正反查 (Bi-directional Recipe Viewer)[/b]
[list]
[*] [b]快捷键快速查询[/b]：鼠标悬停按 [b]R[/b] 查合成配方，按 [b]U[/b] 反查所有用途（含原料、机器催化、工具与性质载体）。
[*] [b]动态候选轮播与流体单位[/b]：矿物标签与替代原料在格内平滑轮播；液体精确显示 mL 容量（[i]1k = 1000mL[/i]）。
[*] [b]爱心配方样板[/b]：在配方旁点击爱心将该产出方式标为首选样板，支持设置无配方基础原料。
[/list]

[b]3. 书签管理与合成链平衡 (Bookmarks & Crafting Chains)[/b]
[list]
[*] [b]一键收藏[/b]：按 [b]A[/b] 或中键收藏条目；在配方页按 [b]Shift + A[/b] 收藏当前配方。
[*] [b]自由划选编组[/b]：在书签栏左侧空白处拖拽即可快速编组，拖拉括号两端轻松调节范围。
[*] [b]智能合成链（灰括号变绿）[/b]：右键点击分组括号开启合成链，悬停查看净产物、原料缺口、所需工具及副产物；[b]Shift[/b] 固定悬浮窗逐级溯源。
[*] [b]自动制作与补齐[/b]：在原生制作面板中对绿色合成链按 [b]Shift + C[/b] 自动制作，按 [b]Ctrl + Shift + C[/b] 自动根据随身库存补齐差额！
[/list]

[b]4. 深度游戏适配与联机保护 (Native Integration & Multiplayer)[/b]
[list]
[*] [b]智能避让[/b]：打开宝箱、交易、医疗、液体转移或自定义面板时 NEI 自动收起，关闭后立即恢复。
[*] [b]Together 联机适配[/b]：每批制作等服务器确认后再提交下一批。联机自动制作不支持手动锁定材料的订单；超时停止后，重试前请检查背包。
[*] [b]自由排版与材质包[/b]：支持在扳手设置中拖动调整面板尺寸与位置；支持通过 [i]resourcepacks/active/[/i] 替换全套贴图。
[/list]

[size=5][b][color=#35d6e8]◆ 快捷键一览 / CONTROLS & SHORTCUTS[/color][/b][/size]

[spoiler]
[list]
[*] [b]O[/b] — 开关侧栏 / Toggle the NEI overlay with the inventory or terminal open.
[*] [b]R / U[/b] — 悬停查询配方／用途 / Hover an item to look up its recipes or uses.
[*] [b]Ctrl + F[/b] — 聚焦搜索栏 / Focus search; right-click the field to clear it.
[*] [b]A or middle-click / Shift + A[/b] — 收藏物品／配方 / Toggle an item bookmark or save the current recipe.
[*] [b]Shift + click tooltip ID[/b] — 复制物品 ID 或来源 / Copy the item ID or mod name from its tooltip.
[*] [b]Drag the left margin / Alt + left-click[/b] — 建组／解组 / Group bookmarks by dragging; Alt-click a bracket to ungroup.
[*] [b]Right-click a bracket[/b] — 开启合成链 / Toggle crafting-chain planning for the group. Hold Shift over a green bracket to pin the tooltip and see the steps.
[*] [b]Shift + C / Ctrl + Shift + C[/b] — 在原生制作菜单制作书签链／补齐差额 / In the native crafting menu, craft the bookmarked target or top it up.
[*] [b]Ctrl + click wrench[/b] — 切换配方和作弊模式 / Toggle recipe and cheat modes. Single-player cheats require opt-in; multiplayer permissions come from the host.
[*] [b]Backspace[/b] — 返回配方历史 / Go back in recipe history.
[/list]
[/spoiler]

[size=5][b][color=#35d6e8]◆ 安装说明 / INSTALLATION[/color][/b][/size]

[b]运行环境要求：[/b]
1. 游戏必须为 [b]Mono[/b] 版本（Casualties: Unknown）；
2. 基础模组框架：[b]BepInEx 5 (Mono)[/b]；
3. 必备前置库：[b]CUCoreLib (1.1 或更高版本)[/b]。

[b]手动安装步骤：[/b]
[list=1]
[*] 确保彻底关闭游戏；
[*] 下载发布压缩包 [i]NotEnoughItems-<版本号>.zip[/i]；
[*] 解压压缩包，将包内顶层的 [b]NotEnoughItems[/b] 文件夹整个复制并拖入游戏的 [b]BepInEx/plugins/[/b] 目录中；
[*] 确保安装后的路径为：[i]Casualties Unknown/BepInEx/plugins/NotEnoughItems/NotEnoughItems.dll[/i]；
[*] 启动游戏即可自动挂载生效。
[/list]
