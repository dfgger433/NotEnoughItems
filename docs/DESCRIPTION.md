# Not Enough Items (NEI) — GitHub Repository Description

## 中文 (Chinese)

### GitHub About 短描述（1 行）
适用于《Casualties: Unknown》的 Not Enough Items (NEI) 物品目录与配方查询 BepInEx 模组。

### 仓库简介（3 句）
本项目是面向游戏《Casualties: Unknown》的 Not Enough Items (NEI) BepInEx 移植版，为原版背包与终端提供物品目录浏览、配方与用途正反查、书签及合成链规划等功能。模组深度适配原生容器、拖拽布局与高级搜索过滤，并支持单机作弊与 Together 联机协同制作。同时提供简洁的机器配方扩展接口与材质包替换能力，方便玩家与模组开发者扩展使用。

## English

### GitHub About Short Description (1 line)
Not Enough Items (NEI) item catalog and recipe viewer mod for Casualties: Unknown.

### Repository Summary (3 sentences)
A BepInEx port of Not Enough Items (NEI) for Casualties: Unknown, bringing an in-game item catalog, recipe/usage viewer, bookmarks, and crafting chain planning to player inventories and terminals. It integrates seamlessly with native containers, customizable layouts, advanced search filters, and supports both singleplayer cheat utilities and Together multiplayer crafting. The mod also provides an extensible recipe registration API and custom UI resource pack support for community modders.
